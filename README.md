# 场刊

影视剧介绍。一页一份片单：剧名、时间、主创、主演、剧情和看点。中文名旁附英文。

## 现在有什么

[index.html](index.html) 是《纽约时报》「21 世纪 100 部最佳剧集」的整理页。原榜名次保留，按类型重排：

| 分区 | 部数 |
| --- | --- |
| 犯罪 | 13 |
| 历史 | 7 |
| 权谋 | 10 |
| 喜剧 | 28 |
| 科幻奇幻 | 13 |
| 人生 | 20 |
| 纪实 | 9 |

页内搜索认中文名、英文名、主创、主演和名次。回车或点选结果会跳到那一部。

播出年份按名单原文。仍在播的标为「至今」。中文名用较通行的译名，搜索也认常见别名。剧情和看点是根据公开资料写的简要说明，不是时报原文。

## 本地打开

用浏览器打开 `index.html` 即可。没有构建步骤，也没有依赖。
